# project-blueprints

Dieses Repository enthält projektspezifische Unterlagen zu Recherche,
Planung, Aufgabenverfolgung und Verifizierungsrichtlinien.

## Erforderliche Struktur

Jedes Projekt muss genau einen Ordner verwenden.

Jeder Projektordner muss diese Dateien enthalten:

- `RESEARCH.md` für Fakten, Anforderungen, Rahmenbedingungen,
  Referenzen und technische Erkenntnisse.
- `PLAN.md` für die vorgeschlagene Lösung, Struktur,
  Designentscheidungen und die Reihenfolge der Umsetzung.
- `TASKS.md` für konkrete Umsetzungsschritte als Aufgabenliste.
- `TESTS.md` für ausführbare Prüfungen zur Verifikation einer
  erfolgreichen Umsetzung.

## Regeln für KI

1. Verwende pro Projekt genau einen Ordner.
2. Halte alle Inhalte innerhalb des zugehörigen Projektordners.
3. Erstelle keine zusätzlichen Dateien, außer wenn dies ausdrücklich
   verlangt wird.
4. Erstelle die Dateien in dieser Reihenfolge:
   `RESEARCH.md`, `PLAN.md`, `TASKS.md`, `TESTS.md`.
5. Halte die Inhalte präzise, technisch und projektspezifisch.
6. Halte `TESTS.md` auf ausführbare Validierung fokussiert, nicht auf
   lange Erklärungen.
