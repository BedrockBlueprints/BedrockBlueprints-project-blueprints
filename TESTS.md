# TESTS.md

Use this file to define runnable tests that verify the implementation
works as intended.

## Purpose

Document only executable or directly performable checks.
Each test should confirm a concrete requirement or expected result.

## Recommended content

For each test, keep the description short and include:

- what is tested
- how to run it
- expected result

## Rules

1. Prefer commands, procedures, or measurable checks.
2. Keep steps reproducible and unambiguous.
3. Map tests to the implemented requirements when possible.
4. Avoid long design explanations or duplicated planning content.
5. Update the file when implementation or verification changes.
