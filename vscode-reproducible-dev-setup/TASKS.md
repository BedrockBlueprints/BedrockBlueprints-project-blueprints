# TASKS

- [ ] Projektordner `.vscode/` anlegen (falls noch nicht vorhanden).
- [ ] Projektrelevante Einstellungen in `.vscode/settings.json` definieren.
- [ ] Empfohlene Extensions in `.vscode/extensions.json` festlegen.
- [ ] Optional: `.vscode/tasks.json` für Build/Test/Lint-Standardtasks erstellen.
- [ ] Optional: `.vscode/launch.json` für Standard-Debug-Konfigurationen erstellen.
- [ ] Extension-Manifest (`.vscode/extensions.list`) generieren und committen.
- [ ] Bootstrap-Skript zur Extension-Installation erstellen und idempotent testen.
- [ ] Dokumentation „Setup auf neuem System“ mit OS-spezifischen Installationskommandos ergänzen.
- [ ] Teamreview für Baseline-Settings durchführen.
- [ ] Regel etablieren: Änderungen an `.vscode` nur per PR.
